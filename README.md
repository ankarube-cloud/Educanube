# Educanube
Repositorio para los recursos de básica primaria es un espacio diseñado para organizar, almacenar y compartir material pedagógico el cual fortalezca los procesos de enseñanza y aprendiza en las instituciones educativas
Objetivo
--------
Facilitar el acceso, la organización y el uso de recursos educativos digitales que apoyen los procesos de enseñanza y aprendizaje en la básica primaria, promoviendo prácticas pedagógicas innovadoras, inclusivas y de calidad dentro de la institución y contribuyendo a la ampliación de los contenidos académicos.

Tipos de recursos
-----------------
- Material de clase (guías, fichas, planes de clase)
- Recursos multimedia (audios, videos, presentaciones)
- Actividades (ejercicios, hojas de trabajo)
- Instrumentos de evaluación (rúbricas, pruebas)
- Objetos de aprendizaje (microcontenidos reutilizables)

Sistema de metadatos
--------------------
Cada recurso publicado debe incluir metadatos para facilitar su búsqueda, organización y reutilización. La estructura principal de metadatos contiene las secciones:
- Identificación (título, autor, fecha)
- Clasificación (asignatura, grado, tipo, tema)
- Descripción
- Acceso (formato, enlace, derechos de uso, disponibilidad)

Roles y permisos
----------------
- Administrador: gestión completa del repositorio y usuarios.
- Equipo directivo: supervisión, validación de contenidos institucionales.
- Docentes: creación, edición y subida de recursos pedagógicos.
- Estudiantes: acceso para consulta y descarga; participación en actividades.
- Familia / acudiente: acceso a materiales orientativos y evidencias.

Cómo contribuir
---------------
1. Revisar la guía de metadatos (METADATA_SCHEMA.md) y usar el formato de ejemplo (resources_example.yaml).
2. Añadir el archivo del recurso en la carpeta correspondiente (/resources/ o /assets/) siguiendo la convención de nombres.
3. Incluir o actualizar el registro de metadatos (YAML o JSON) asociado al recurso.
4. Abrir un Pull Request con descripción clara del recurso, asignatura, grado y propósito pedagógico.

Estructura sugerida del repositorio
-----------------------------------
- /resources/          → archivos de recursos (pdf, mp4, mp3, pptx, docx)
- /metadata/           → registros de metadatos (yaml / json)
- /docs/               → documentación y guías (METADATA_SCHEMA.md, ROLES.md, CONTRIBUTING.md)
- README.md

Licencia y derechos
-------------------
- Derechos de uso: uso institucional (especificar si requiere atribución o si es interno).
- Indicar siempre la fuente y autoría del recurso en los metadatos.

Contacto
--------
Para dudas o soporte sobre la plataforma y la gestión de recursos, contactar con el administrador del repositorio o el equipo directivo.
